# Platform logos

- `apple.svg`: Apple logo vector from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/apple.svg), distributed under CC0.
- `windows.svg`: Windows 11 logo from [Simple Icons v11](https://github.com/simple-icons/simple-icons/blob/11.0.0/icons/windows11.svg), CC0.
- `flag-uk.svg` and `flag-it.svg`: [Flag Icons v7.2.3](https://github.com/lipis/flag-icons/tree/v7.2.3/flags/4x3), MIT license.
- `sun.svg` and `moon.svg`: [Lucide v0.468.0](https://github.com/lucide-icons/lucide/tree/0.468.0/icons), ISC license.

These are upstream icon files, not custom-drawn replacements. License texts are
included alongside the assets. `minimal.css` and `landing-scroll.js` contain the
website's own styles and section-navigation behavior.

The logos identify the operating systems supported by each download. Apple and
Windows are trademarks of their respective owners.
